## Project State

This is a Next.js personal task-management app inspired by Things 3. The app supports email/password authentication with Better Auth and task management backed by Neon PostgreSQL through Drizzle.

Project support docs include Things 3 reference material and UI reference images, ADR-001 for the personal task-management model, ADR-002 plus an architecture migration plan for moving to Next.js, Neon PostgreSQL, Drizzle, and Better Auth, ADR-003 for the RSC-first boundary, ADR-004 for separate auth routes, ADR-005 for dnd-kit task reordering, ADR-006 for Base UI as the default UI component system, ADR-007 for local UI state and TanStack Query mutation ownership, ADR-008 for local Oxlint statement padding, proposed ADR-009 plus an architecture plan for database-theft encryption, accepted ADR-010 plus an implementation plan for optional TOTP and backup-code authentication, ADR-011 for Ultracite-managed Oxlint and Oxfmt presets, ADR-012 for retained completed tasks, an architecture component-composition diagram, and an implemented password-reset architecture plan.
