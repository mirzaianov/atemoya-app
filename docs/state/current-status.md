## Project State

This is a Next.js personal task-management app inspired by Things 3. The app supports email/password authentication with Better Auth and task management backed by Neon PostgreSQL through Drizzle.

Project support docs include Things 3 reference material and UI reference images, ADR-001 for the personal task-management model, ADR-002 plus an architecture migration plan for moving to Next.js, Neon PostgreSQL, Drizzle, and Better Auth, ADR-003 for the RSC-first boundary, ADR-004 for separate auth routes, ADR-005 for dnd-kit task reordering, ADR-006 for Base UI as the default UI component system, ADR-007 for local React state and TanStack Query mutation ownership, ADR-008 for local Oxlint statement padding, accepted ADR-009 plus an approved architecture and rollout plan for passive database-exfiltration protection using maintenance-only shadow-column conversion, a Better Auth Drizzle adapter decorator, an application gate with an explicit invocation drain, versioned application equality normalizers, strict allowlist logging, and an isolated Neon development test database; implementation now includes the guarded real-database harness, database-free cryptography primitives, strict logging boundary, additive shadow schema, development-key configuration, encrypted task persistence, encrypted Better Auth identity/session/verification persistence, Better Auth-native encrypted backup-code storage, the maintenance write barrier, conversion preflight, restartable atomic conversion batches, the guarded local operator command with failure injection, and the accepted development rehearsal, while the contract migration and production rollout remain pending, accepted ADR-010 plus an implementation plan for optional TOTP and backup-code authentication, ADR-011 for Ultracite-managed Oxlint and Oxfmt presets, ADR-012 for retained completed tasks, an architecture component-composition diagram, and an implemented password-reset architecture plan.
